# Math Masti Quest

A browser-based mathematics practice game for Grade 4 students in India, designed to be ICSE/CISCE-friendly.

## Topics
- Numbers and place value
- Addition and subtraction
- Multiplication and division
- Factors and multiples
- Fractions and decimals
- Measurement
- Time and money
- Geometry
- Patterns and data handling
- Word problems

## Features
- Fresh randomized questions on every play
- Topic practice or mixed quest
- Score and streak system
- Hints and immediate feedback
- Parent/teacher progress report stored locally in the browser
- Mobile-friendly, no installation required

Open `index.html` or host the repository with GitHub Pages.


## Accounts and cloud progress

The app now supports account-scoped progress using Firebase Authentication and Cloud Firestore:

- Email/password signup and sign-in
- Google sign-in
- Password reset
- Child/Student or Parent/Adult account role
- Persistent browser sessions
- Per-user cloud mastery/progress
- Local guest mode
- Migration of existing device progress into the first cloud account

Before cloud accounts can be used on the live site, complete the one-time steps in [SETUP_FIREBASE.md](SETUP_FIREBASE.md). Until then, **Continue on this device without sign-in** keeps the game usable locally.
